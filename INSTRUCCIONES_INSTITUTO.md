# 🏫 Cómo abrir y continuar el proyecto en el ordenador del instituto

Sigue estos 3 sencillos pasos cuando llegues al PC del instituto:

---

### Paso 1: Clonar el repositorio en el ordenador del instituto
Abre la terminal (PowerShell o Git Bash) y escribe:
```bash
git clone https://github.com/DAW2ProyectoIntermodular/ProyectoIntermodular.git
cd ProyectoIntermodular
```

*(Si ya lo tenías clonado de antes, entra en la carpeta y haz un pull:)*
```bash
git pull origin main
```

---

### Paso 2: Abrir el proyecto en Antigravity
1. Abre la aplicación de **Antigravity**.
2. Para que te aparezca en la pestaña de proyectos:
   - Haz clic en **"Open Folder..."** (o **"File" > "Open Folder..."** / **"Abrir carpeta..."**).
   - Selecciona la carpeta **`ProyectoIntermodular`** que acabas de clonar.
3. Una vez abierta, el proyecto ya quedará registrado en tu pestaña de **"Projects"** / **"Workspaces"** de Antigravity.

---

### Paso 3: Retomar la conversación con el agente
Abre un nuevo chat en Antigravity dentro de ese espacio de trabajo y pega simplemente esta frase:

> *"Hola, lee `docs/ESTADO_ACTUAL_Y_CONTINUACION.md` y `docs/CONTEXTO_OFICIAL_PROYECTO.md` y continuamos trabajando desde donde lo dejamos."*

El agente cargará de golpe todo el contexto, sabrá que los contratos OpenAPI están corregidos y listos, y continuará exactamente en el punto actual.
